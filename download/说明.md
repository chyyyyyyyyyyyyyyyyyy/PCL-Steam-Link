# PCL 联机版（Steam 转发）交付说明

## 这是什么

这是基于 [Meloong-Git/PCL](https://github.com/Meloong-Git/PCL) 官方源码 **tag `2.13.1.1`** 编译出来的 PCL 启动器，
在**保留原版全部功能**（尤其是完整的**游戏下载**：原版游戏 / Mod / 整合包 / 数据包 / 资源包 / 光影包）的前提下，
把原本被开源版阉割掉的「**联机**」页面补了回来，并把联机底层实现换成
[connecttool-qt](https://github.com/moeleak/connecttool-qt) 那套思路：**用 Steam 的网络（P2P / 中继）把游戏端口转发出去**，
不需要公网 IP、不需要端口映射、不需要额外服务器。

> **联机模块的出处（重要）**
> 「联机」用的转发模型参考自开源项目 **connecttool-qt**：作者 **Ji Fuyao**（GitHub: [moeleak](https://github.com/moeleak)），
> 许可 **MIT**（Copyright (c) 2025 Ji Fuyao），仓库 https://github.com/moeleak/connecttool-qt （本版参考的是 `1.6.0`，commit `7a2d7aa`）。
> 它用 Steam 网络（`SteamNetworkingSockets`）做 TCP 转发 / 类 Tailscale 的 TUN 组网，本项目是照着这个思路用
> **C# + Steamworks.NET 重写**的 `PCLink`（没有复制它的 C++ / Qt 源码），并补了 `host` / `join` / `selftest` 命令行接口给启动器调用。

> 为什么用 2.13.1.1 而不是最新版：最新版（2.99.x）的下载模块被大幅精简（`PageDownloadInstall` 缩水、`PageDownloadModify` 直接删除），
> 没有完整的「原版游戏下载 / 安装新版本」体验；`2.13.1.1` 是带完整下载功能的一版，且联机页源码与最新版**逐字节相同**，移植无需适配。

产物就是本目录下的 `Plain Craft Launcher 2.exe`，可直接当作原版启动器使用。

## 怎么用

1. 关掉正在运行的 PCL。
2. 用本目录的 `Plain Craft Launcher 2.exe` 替换/覆盖你原来的启动器（或放到任意目录，只要它有权限读写自己的数据目录）。
3. 启动后：它会读取你现有的配置（`HKCU\Software\PCL`）和游戏目录，**版本列表、登录、下载、设置、整合包等全部行为与原版一致**。
   - 已验证：能直接读到你 `%APPDATA%\.minecraft\versions` 里的版本（`26.3`、`26.4-snapshot-5`）。
4. 顶部导航第 3 个按钮就是「**联机**」（原版开源版里这个按钮被强制隐藏，现已恢复；顺序为 启动 / 下载 / 联机 / 设置 / 更多）。

## 联机怎么玩

两个人都必须满足：

- 装了 **正式的 Steam 客户端**（不是网页版），并且**已经登录**；
- 双方 Steam **互为好友**（Steam P2P 连接更稳妥）；
- 游戏本体版本一致。

房主（开服的那位）：

1. 先进单人游戏，按 `Esc` → 「**对局域网开放**」，记下端口（默认 `25565` 之类，游戏会提示）。
2. PCL → 「联机」 → 「创建房间」 → 输入刚才那个端口。
3. 页面完成页会显示「房间号」（就是房主的 17 位 Steam ID）并自动复制，把它发给朋友。
4. 朋友在游戏里通过「多人游戏 → 直接连接」连 `localhost:<页面显示的本地入口端口>`。

加入方：

1. PCL → 「联机」 → 「加入房间」 → 粘贴房主给的房间号。
2. 连上后页面会显示本地入口，例如 `localhost:25566`，游戏里连这个地址即可。

原理：PCL 会释放一个自带的 `PCLink.exe` 小工具到 `%APPDATA%\PCL\PCLink\`，
它用 Steam 的 `ISteamNetworkingSockets`（AppID 480，与 connecttool 相同做法）建立 P2P 连接，
房主进程连本地游戏端口，加入方在本地开一个 TCP 监听把流量灌进 Steam 管道，所以只有本地回环流量，不需要任何端口映射。

## 已知限制 / 注意

- **已在装有 Steam 并登录的机器上实测「创建房间」成功**（Steam ID `76561199705557473`，房间号正常显示并自动复制，
  `PCLink.exe` 日志 `房间已创建` 正常）。跨机器的真实 P2P 连通性仍需两台机器各登录一个 Steam 账号实测。
- **`steam_api64.dll` 必须与 `Steamworks.NET 2024.8.0` 匹配**：connecttool-qt Release 包里带的那个 dll（317080 字节）是更新一代的
  Valve 运行库，已经移除了 `SteamAPI_ISteamClient_GetISteamGameSearch`，而 Steamworks.NET 2024.8.0 的 `SteamAPI.Init()` 会强求这个导出，
  结果就是启动时直接 `EntryPointNotFoundException` → 页面报「无法加载 Steam 组件：Entry point was not found.」。
  现改用 SDK 同代的 Valve 可再分发库（300392 字节，取自本机 Steam 游戏目录内的 `steam_api64.dll`），`Init()/P2P/中继` 全部正常。
  如果以后有人重编 `PCLink.exe`，**别换回 connecttool 包里的那个 dll**。
- **正版登录（微软账号）已修好**：开源版 `ModSecret.vb` 里 `OAuthClientId` 是空的，导致请求设备代码时被微软回
  `400 BadRequest / AADSTS900144: The request body must contain the following parameter: 'client_id'`，浏览器也就不会打开。
  现已预置官方发行版使用的 ClientId（`fe72edc2-3a6f-4280-90e8-e2beb64ce7e1`），点「登录」能正常拿到 8 位代码、自动复制并打开
  `https://www.microsoft.com/link`。若你想换成自己的 Azure 应用，仍可设环境变量 `PCL_MS_CLIENT_ID` 覆盖。
- **CurseForge 下载仍不可用**：这条也需要官方私有的 API Key，开源版里被清空，官方 exe 里也没有可提取的明文，所以
  「下载 → 社区资源」里从 CurseForge 拉取 Mod 会失败（Modrinth / 原版游戏下载不受影响）。

- 开源版原本的「联机」是基于 EasyTier 公共节点的，但那份实现需要官方服务器下发的 `ServerConfig.json`
  （我们这边请求一直 403，开源版因此根本跑不起来），所以**联机改为 Steam 实现**，其余功能不动。
- 本 exe 41MB（原版约 6MB），因为多嵌了一个 35MB 的 `PCLink.exe`（.NET 8 自包含单文件）。
- Steam 联机功能属于"非官方网络用途"，Steam 账号风险请自行评估（connecttool 的 README 也提示过同类风险）。

## 改了什么（摘要）

1. `Pages/PageSetup/PageSetupUI.xaml.vb`：不再强制把 `BtnTitleSelect2`（联机）设为 Collapsed。
2. `Pages/PageSetup/Settings.vb`：删掉 `ForcedSettings` 里对 `UiHiddenPageLink`、`UiHiddenSetupLink` 的强制赋值（第二道隐藏闸门，不删则顶部「联机」按钮仍然不显示）。
3. `Pages/PageLink/PageLinkMain.xaml.vb`：整个联机页重写为 Steam 版本（原 1116 行 EasyTier 逻辑替换为调用 `PCLink.exe`）。
4. `Pages/PageLink/PageLinkMain.xaml`：两处文案（邀请码 → 房间号）。
5. `FormMain.xaml.vb`：删掉 `Return 'TODO: 联机复活赛` 这一行，恢复「切回窗口时读取剪贴板、自动加入联机房间」的原版行为；并删掉开源版启动提示里「正版登录需自行申请 Client ID」那一条。
6. `My Project/Resources.resx`：内嵌 `Resources/PCLink.exe`。
7. `Resources/PCLink.exe`：新增的 Steam 转发工具（源码见 `PCLink-源码/`）。
8. `Modules/ModSecret.vb`：`OAuthClientId` 预置官方发行版使用的 ClientId（开源版为空 → 正版登录 400 AADSTS900144、浏览器不打开）。
